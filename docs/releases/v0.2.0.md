**Roadkill 0.2.0: network play.**

Multi Player works again: the game's own 1997 lobby, chat, car select and matches, between Roadkill players over the internet or a home network, up to 8 players. The game's network code runs unchanged; underneath it, Roadkill's own UDP protocol takes the place of DirectPlay (Microsoft's DirectPlay is not used, so there's no play with the original 1997 game).

**No game data is included.** You need your own Twisted Metal 2 PC CD; `import_disc.py` sets it up (see 0.1.0's notes or `README.txt`).

## Playing online

- **Host:** Multi Player > Internet TCP/IP > New Game. Your game is listed on the public announce server, `roadkill.horrible.dev`, and on your home network.
- **Join:** Multi Player > Internet TCP/IP > Join, and pick a game. Or ask a host directly: `[net] join = <address>:27420` in `roadkill.ini`.
- **Names:** type them in the game, or set `[player] name`, `[player] alias` and `[net] session_name` in `roadkill.ini`.
- **Ports:** UDP 27420 (the next free one up to 27429). The announce server introduces players so most home routers need no setup; if a friend can't join you, forward UDP 27420.
- `[net] public = 0` keeps a game you host off the public list.

## What's new

- **Network play** (`src/host/net`): sessions, players, host migration, a reliable channel and a per frame channel, keepalives that drop a player who vanishes, every packet checked before the game sees it. `docs/NETWORK.md` has the details.
- **The announce server** (`server/announce`): lists games and introduces players through their routers (UDP hole punching); it never carries game traffic or passwords.
- **Cross-play with the original Xbox:** Roadkill also builds for the original Xbox (`port/xbox`, with your own XDK via OXDK), and Xbox and PC players play together. The Xbox build isn't part of this release.
- **Music as MP3:** `import_disc.py` / `convert_music.py` turn the CD's audio into about 45 MB of MP3s (since 0.1.0's update).
- Fixes found on the way: the network screens' saved names, the lobby's player list colors, the join screen's first session, the current drivers list.

## Not yet

- No relay: two players behind strict (symmetric) NATs can't reach each other; port forwarding helps.
- No computer opponents in network games (as in the original).
- Tested so far: up to three players on one network, and Mac / Xbox; reports from real internet games are welcome.
