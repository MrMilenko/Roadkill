**Roadkill 0.1.0: Twisted Metal 2 for Windows 95, native on Windows, macOS and Linux.**

The 1997 PC game, built from the [TM2-Win9x Decomp](https://github.com/MrMilenko/TM2-Win9x-Decomp): the original `TM2.EXE` decompiled into C, every function the game reaches checked against the original machine code. It plays like the 1997 PC game by default; every change is a switch in `roadkill.ini`, off unless you turn it on.

**No game data is included.** You need your own Twisted Metal 2 PC CD.

Each zip holds the program (one file, nothing to install), an empty `data` folder, `import_disc.py`, `convert_music.py` and a `README.txt`.

## Setting up from your disc, a .cue / .bin or an .iso

1. Unzip anywhere.
2. Install Python 3.8+ and ffmpeg (ffmpeg is for the music):
   - Windows: `winget install Python.Python.3.12 Gyan.FFmpeg`
   - macOS: `brew install python ffmpeg`
   - Linux: `sudo apt install python3 ffmpeg` (or your distribution's)
3. In a terminal in the Roadkill folder, point `import_disc.py` at your disc:
   - Windows: `py import_disc.py "C:\path\to\Twisted Metal 2.cue"`
   - macOS / Linux: `python3 import_disc.py "/path/to/Twisted Metal 2.cue"`

   It copies the game's files out of the image (no mounting) and turns the CD music into MP3s (about 45 MB) in `data`.

What to give it:

| Source | You get |
|---|---|
| `.cue` / `.bin` (a rip of the CD) | the game and its music: the best |
| `.iso` | the game, no music (an .iso can't hold CD audio) |
| the CD itself (`D:\`, `/Volumes/...`, `/media/cdrom`) | the game, no music: for the music rip the CD to .cue / .bin (Windows: ImgBurn "Create image file from disc"; macOS / Linux: `cdrdao read-cd --read-raw --datafile tm2.bin tm2.toc` then `toc2cue tm2.toc tm2.cue`) |

Without ffmpeg the script copies the .cue / .bin in as they are, and Roadkill plays the music from them.

By hand instead: copy everything from the CD into `data` (`TM2.EXE` directly in it), and the CD's `.cue` / `.bin` too for the music.

4. Start Roadkill: `roadkill.exe` on Windows, `roadkill` on macOS and Linux. macOS: the build isn't notarized, so the first start is right-click > Open > Open (or System Settings > Privacy & Security > Open Anyway). If the files aren't found, Roadkill tells you which folder it looked in.

## What works

- The single player game: the menus, tournament and challenge matches, the movies, sound effects and the CD music
- Keyboard as in the original; a game controller as the game's joystick (Options > Input Config)
- `roadkill.ini` (written on the first run) for fullscreen, window size, widescreen, a higher 3D resolution, volumes, looping music and fixes for the original's own bugs: all off by default
